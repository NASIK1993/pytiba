# Character Studio — 3D character creator for Android

An interactive 3D dress-up / character-creator app. It's built with
[three.js](https://threejs.org) and packaged for Android with
[Capacitor](https://capacitorjs.com). Every character is generated
procedurally from 3D primitives, so the app needs no model files or downloads.

## Features

- **Body:** skin tone, eye colour, expression (happy / calm / grin / surprised), height
- **Hair:** 7 styles (short, bob, long, ponytail, buns, curly, spiky) and any colour
- **Outfit:** tops (t-shirt, hoodie, sweater, jacket), bottoms (jeans, cargo, shorts, skirt, long skirt), shoes (sneakers, boots, slip-ons), each in any colour
- **Extras:** beanie, cap, headphones, flower clip, glasses, sunglasses, backpack, scarf
- **Poses / animations:** idle, wave, walk, dance, jump, cheer, think, sit, twirl, with smooth blending between them
- **Interaction:** drag to orbit, pinch to zoom, tap the character for a reaction (hop and floating emoji, with haptic feedback)
- **Scene:** 6 backdrops, auto-rotate, a 📷 photo button that saves a PNG snapshot, and a 🎲 randomiser
- Your character, pose and scene are saved automatically on the device

## Run in a browser

```bash
cd character-studio
npm install
npm run dev        # open the printed URL (use your phone on the same Wi-Fi with --host)
```

## Build the Android app

### Option A: GitHub Actions (no local setup)
Every push that touches `character-studio/` runs the **Character Studio APK**
workflow. Download `app-debug.apk` from the run's **Artifacts**, copy it to your phone
and install it (allow "install unknown apps").

### Option B: Locally
Requires Node 22+, JDK 21 and the Android SDK (Android Studio).

```bash
cd character-studio
npm install
npm run android:sync          # builds the web app and copies it into android/
cd android && ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
# or: npm run android:open    (opens the project in Android Studio and runs it on a device)
```

## Project layout

```
character-studio/
├── index.html            app shell
├── src/main.js           scene, camera, touch interaction, UI
├── src/character.js      procedural character + clothing/hair/accessory builders
├── src/poses.js          procedural animations and pose blending
├── src/style.css         mobile-first UI
├── capacitor.config.json Android app id / name
└── android/              native Android project (generated by Capacitor)
```

To add a new outfit, add its id to `OPTIONS` and `LABELS` in `src/character.js`,
then add a `case` to the matching `build*` function.
